请清理博客标签列表，找出应当合并的高度重复标签组。

判定范围：
- 大小写差异、简繁差异、单复数差异；
- 中英文同义、缩写与全称；
- 标点、空格或表达方式不同但含义基本相同。

不要合并：
- 只是主题相关但含义不同的标签；
- 上下位概念；
- 会导致检索粒度明显变差的标签。

输出要求：
1. 若没有需要合并的标签，返回 []。
2. 只输出严格 JSON，不要解释，不要 Markdown 代码块。
3. tags 只能包含输入列表中真实存在的标签。
4. target 是建议保留的规范标签，可从原标签中选择，也可给出更清晰的新标签。
5. reason 用一句话说明为什么它们是高度重复。

格式：
[
  {"tags":["原标签A","原标签B"],"target":"规范标签","reason":"简短原因"}
]

标签列表：
{{tags}}
