硬性规则：
1. 必须为每个输入编号返回且只返回一个 slug；编号必须与输入完全一致，不得缺失、增补或重排。
2. 只输出严格 JSON 数组，不要解释，不要 Markdown 代码块。
3. JSON 格式必须为：[{"id":1,"slug":"example-slug"},{"id":2,"slug":"example-slug-2"}]
4. slug 只能包含英文小写字母 a-z、数字 0-9 和短横线 -；不能有中文、空格、下划线、标点或连续短横线。
5. slug 应简洁、可读、稳定，通常 2—8 个英文词。
6. 对同一作品、同一卷、同一专题或连续章节，必须保持统一前缀；例如“第一卷……、第二卷……”应使用同一作品前缀加 volume/part 标识；同一卷内条目除末尾章节编号外，其余主体应保持一致。
7. 不要逐字机械翻译长标题；保留能区分内容的核心名词、卷号、章节号、主题词。
